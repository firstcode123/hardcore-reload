这个计划不追求"猛"，追求"不断"。先修复底层——睡眠、饮食、日常活动量，再叠加训练强度。8 周见体感，12 周见体型，之后把它变成默认值。
每周训练模板
核心规则
动作库 · 示范动画
点任意动作展开示范动画。优先从零器械区开始——把基础动作做标准，比换花样重要十倍。
安全边界
以下情况立刻停手并就医：胸闷胸痛、头晕黑视、关节尖锐疼痛（非肌肉酸胀）、静息心率异常升高、夜间心悸。
  • 任何动作出现"刺痛/卡顿/弹响伴痛"，换动作而不是硬扛。
  • 腰部不适时，避免仰卧起坐、负重弯腰，改做死虫、臀桥、鸟狗。
  • 连续 3 天睡眠不足 6 小时，主动把训练降一档，别硬练。
  • 感冒发热期间停训，恢复后从上一阶段的一半量重新开始。
  • 本计划为通用健康方案，不替代医生诊断。有基础疾病请先咨询医生。

手机同步
三种方式，按需选一种就够：
  • 本机保存：打开即用，数据存在这个浏览器里，换设备不会自动同步。
  • 同步码：复制一段文本，粘到微信/文件传输助手，在手机上粘回来即完成迁移。
  • 云同步：配置一次 GitHub 令牌，电脑和手机自动双向同步（推荐长期用）。
导出的 json 文件可存网盘，作为总备份。
